# Android-Linux-Tutorial

用平板（Android）设备，免 root 搭建 Linux 开发环境及本地部署Python

## 这个教程能帮你什么

如果你有一台平板（Android设备），并且想知道——

- 能不能用Android学 Linux 命令？
- 能不能用Android学 Python 编程？
- 能不能拥有一个随时打开就能敲代码的移动工作站？

答案是：**能。** 这个教程带你一步一步做到。

## 你将获得

- ✅ 平板（Android端）里的 Ubuntu  系统
- ✅ 完整的 VS Code 开发环境（浏览器打开）
- ✅ Python 3 + Git + Vim 全套工具
- ✅ 看完它可做的事后给你带来一些不一样的思路

## 环境说明

本教程基于 OPPO Pad 4 Pro（Android 15）操作，
其他平板（Android设备）操作大同小异。
所有操作免 root、不需要电脑、不损坏系统。
