# pad-linux-setup

用你手边的安卓平板，免 root、零成本，搭建 Linux 开发环境。

## 这个教程能帮你什么

如果你有一台安卓平板，并且想知道——

- 能不能用它学 Linux 命令？
- 能不能用它学 Python 编程？
- 能不能拥有一个随时打开就能敲代码的移动工作站？

答案是：**能。** 这个教程带你一步一步做到。

## 你将获得

- ✅ 平板里的 Ubuntu 24.04 系统
- ✅ 完整的 VS Code 开发环境（浏览器打开）
- ✅ Python 3 + Git + Vim 全套工具

## 环境说明

本教程基于 OPPO Pad 4 Pro（Android 15）编写，
其他安卓平板操作大同小异。
所有操作免 root、不需要电脑、不损坏系统。
